```bash

# Run first example
python examples/00_hello_world.py

# Run all examples
python examples/01_variables.py
python examples/01_type_conversion.py
python examples/02_operators.py

# Do first exercise
python exercises/00_introduction.py

# See solution
python solutions/00_introduction.py
```

### Start Django Project

```bash
# Navigate to Django project
cd projects\mastery_platform

# Run migrations (already done, but here's the command)
python manage.py migrate

# Start development server
python manage.py runserver

# Access at: http://127.0.0.1:8000/
```

### Run Tests

```bash
# All tests
pytest

# Tests in exercises folder
pytest exercises/ -v

# Tests with coverage
pytest --cov=.
```
